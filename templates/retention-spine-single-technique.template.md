## PHẦN 3 — PHA D VERIFY (thêm 2 phép đếm cho A3)

Chạy TRƯỚC audit nặng. Giữ nguyên L3/L4/L5/L6 của Pha D gốc, **cộng thêm**:

```python
import re
tts = re.search(r"## TTS SCRIPT\s*(.*)", open(PATH, encoding="utf-8").read(), re.DOTALL).group(1)
words = tts.split()
def wi(sub):                      # word index của 1 chuỗi
    i = tts.find(sub)
    return len(tts[:i].split()) if i >= 0 else -1

SECOND_PROMISE_CUE = "..."        # câu gieo lời hứa thứ hai (dán nguyên văn)
PAYOFF_CUE         = "..."        # câu tiết lộ kỹ thuật
SECOND_PAYOFF_CUE  = "..."        # câu trả lời hứa thứ hai

p_plant, p_main, p_second = wi(SECOND_PROMISE_CUE), wi(PAYOFF_CUE), wi(SECOND_PAYOFF_CUE)
print("gieo lời hứa 2 @word", p_plant, "-> ", "OK" if 0 <= p_plant <= 145 else "FAIL: gieo sau giây 55")
print("thứ tự payoff        -> ", "OK" if p_main < p_second else "FAIL: lời hứa 2 trả trước payoff chính")
print("tổng từ", len(words), "->", "OK" if 1200 <= len(words) <= 1500 else "FAIL: lệch video_length")
```

|---|---|---|
| Lời hứa thứ hai gieo **< giây 55** | ~word 145 | |
| Lời hứa thứ hai trả **sau** payoff chính | thứ tự word index | |
| Tổng từ trong `video_length` | 1.200–1.500 | |
| L6 · số/bằng chứng < giây 20 | *(Pha D gốc)* | |
